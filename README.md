# Bruno - AI Assistant

Documentazione pubblica del collaudo interno Essedi. Questo repository contiene esclusivamente le pagine informative; non ospita il codice applicativo, credenziali, allegati o conversazioni.

## GitHub Pages

In Settings → Pages scegliere **Deploy from a branch**, branch **main**, cartella **/(root)** e salvare.

Pagine previste dopo l'attivazione:
- https://diegoessedi.github.io/bruno-info/privacy.html
- https://diegoessedi.github.io/bruno-info/terms.html

Sito HTML/CSS statico, senza dipendenze, script o tracker aggiunti. Non occorrono build, token o servizi a pagamento.
